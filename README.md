# AI-BASED-PROJECT-JUDGE-VIVA-SIMULATOR
AI Based Project Judge is a GenAI-powered evaluation and viva-simulation platform for engineering capstones. It ingests structured project data, reports, and code to score submissions against strict rubrics. Moving beyond basic feedback, it outputs numerical grades, pinpoints key weaknesses, suggests fixes, and simulates a multi-persona viva panel.
